LedgerMind is a web-based system that helps identify risky financial accounts by analyzing how their transaction behavior changes over time. Instead of directly labeling transactions as fraud, the system assigns a Trust Score based on how closely current behavior matches past patterns.

Users upload transaction data through a React-based interface, and a machine learning model analyzes the data in the backend. The final output is a clear dashboard showing trust scores and highlighting accounts that need attention, helping auditors focus on high-risk cases faster and more efficiently.
